# Phase 1 – de scène

Deze map bevat de losse, kale fase 1-scène: een eigen Vite-project met één leesbaar `main.js`
(scène, licht, OrbitControls, klikken om aan/uit te zetten, draaiende wieken, bewegende zon en vallende regen).

## Hoe het tot stand is gekomen

- De code is **manueel geschreven** door mij (Lukas), zoals gevraagd door de leerkracht.
- Ik heb **licht gebruikgemaakt van AI** (chatberichten), enkel om slecht gedocumenteerde dingen duidelijker te maken — bijvoorbeeld hoe Three.js-onderdelen zoals `OrbitControls`, raycasting of de render loop precies werken. De AI heeft geen code voor mij gegenereerd; ik heb alles zelf getypt en uitgewerkt.
